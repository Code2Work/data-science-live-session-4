Hepsi aynı şeyi yapar: "başka bir sorgunun sonucunu kullan." Fark: ömrü ve ismi.

🤔 Örnek 1 — Soru

Eurovision'da ortalama puanın üstünde kalan tüm yarışmalar

Önce ortalama lazım, sonra ondan büyük olanlar.

İki ayrı sorgu yazmak yerine?

✅ Örnek 1 — Çözüm: Subquery

Tek sayı dönen subquery

SELECT year, to_country, performer, points_final
FROM eurovision.contestants
WHERE points_final > (
    SELECT AVG(points_final)
    FROM eurovision.contestants
)
ORDER BY points_final DESC;

İçerideki sorgu önce çalışır → tek sayı döner (≈ 88) → dış sorgu o sayıyı kullanır.

🤔 Örnek 2 — Soru

En çok kazanan ülkenin tüm yarışmaları

Önce o ülkenin kim olduğunu bul, sonra o ülkeyi filtrele.

✅ Örnek 2 — Çözüm

Subquery iki adımı tek sorgu yapar

SELECT year, performer, place_final, points_final
FROM eurovision.contestants
WHERE to_country = (
    SELECT to_country
    FROM eurovision.contestants
    WHERE place_final = 1
    GROUP BY to_country
    ORDER BY COUNT(*) DESC
    LIMIT 1
);

İç sorgu: 'Ireland' veya 'Sweden' döner → Dış sorgu o ülkenin satırlarını getirir.

🤔 Örnek 3 — Soru

Hiç birinci olamamış ülkelerin tüm yarışmaları

Önce "kazananlar listesini" çıkar, sonra listede olmayanları seç.

✅ Örnek 3 — Çözüm: NOT IN

Liste dönen subquery

SELECT to_country, COUNT(*) AS katilim
FROM eurovision.contestants
WHERE to_country NOT IN (
    SELECT DISTINCT to_country
    FROM eurovision.contestants
    WHERE place_final = 1
)
  AND place_final IS NOT NULL
GROUP BY to_country
ORDER BY katilim DESC;

İç sorgu liste döndü → NOT IN ile o listede OLMAYANLAR.

🤔 Örnek 4 — Soru

Subquery okumak zorlaştı — daha temiz yazalım

Aynı işi WITH ile yapsak nasıl olur?

Subquery'ye isim versek, dışarıda kullansak...

✅ Örnek 4 — Çözüm: WITH

Örnek 1'in WITH versiyonu

WITH genel_ortalama AS (
    SELECT AVG(points_final) AS ort
    FROM eurovision.contestants
)
SELECT year, to_country, performer, points_final
FROM eurovision.contestants, genel_ortalama
WHERE points_final > genel_ortalama.ort
ORDER BY points_final DESC;

WITH = subquery'ye isim ver → dışarıda tablo gibi kullan. Daha okunaklı.

🤔 Örnek 5 — Soru

Türkiye'nin kendi ortalamasının üstünde kaldığı yıllar

İki adım gerekiyor:

1) Her ülkenin ortalamasını hesapla

2) Türkiye'yi seç + ortalamadan büyük puanları al

✅ Örnek 5 — Çözüm: WITH + JOIN

WITH'in asıl gücü

WITH ulke_ortalama AS (
    SELECT to_country, AVG(points_final) AS ort
    FROM eurovision.contestants
    WHERE points_final IS NOT NULL
    GROUP BY to_country
)
SELECT c.year, c.performer, c.points_final,
       ROUND(u.ort::numeric, 1) AS turkiye_ort
FROM eurovision.contestants c
JOIN ulke_ortalama u ON c.to_country = u.to_country
WHERE c.to_country = 'Turkey'
  AND c.points_final > u.ort;

2004 Athena (195) | 2009 Hadise (177) | 2010 maNga (170) | 2003 Sertab (167)

🤔 Örnek 6 — Soru

Türkiye verisini her seferinde yazmaktan sıkıldık

WHERE to_country = 'Turkey' AND place_final IS NOT NULL ...

Bunu kalıcı bir tabloya çevirsek?

✅ Örnek 6 — Çözüm: VIEW

Kalıcı, isimli subquery

-- VIEW oluştur (bir kere)
CREATE OR REPLACE VIEW eurovision.turkiye_yarismalari AS
SELECT year, performer, song, place_final, points_final
FROM eurovision.contestants
WHERE to_country = 'Turkey' AND place_final IS NOT NULL;

-- Artık tablo gibi kullan
SELECT * FROM eurovision.turkiye_yarismalari LIMIT 5;
SELECT AVG(points_final) FROM eurovision.turkiye_yarismalari;

VIEW DB'de KALICI. Aynı sorgu lazım olduğunda her seferinde yazmazsın.

02

Python f-string

% → .format() → f-string

Neden Lazım?

Veri analizinde çıktıyı insana göstermek gerek.

# 🔴 Çirkin
print(name, age, salary)
# → Ali 25 12500.5

# 🟢 Şık
print(f"Merhaba {name}! Maaşın {salary:,.2f} ₺")
# → Merhaba Ali! Maaşın 12,500.50 ₺

Bugünden sonra raporlarınız profesyonel görünecek.

🤔 Soru

"Merhaba Ali, yaşın 25" nasıl yazılır?

Python'da 3 yöntem var, üçü de aynı sonucu verir.

Hangisi en iyisi?

✅ Çözüm: 3 Yöntem

Eskiden Modern'e

# 🔴 ESKİ — % formatting (1990'lar)
print("Merhaba %s, yaşın %d" % (name, age))

# 🟡 ORTA — .format() (Python 2.6+)
print("Merhaba {}, yaşın {}".format(name, age))

# 🟢 MODERN — f-string (Python 3.6+) ⭐
print(f"Merhaba {name}, yaşın {age}")

f-string: değişkenler stringin İÇİNDE → okumak kolay. Yeni kodlarda bunu kullanın.

🤔 Soru

"Pi = 3.14" diye yazmak istiyorum

Tüm ondalıkları değil, sadece 2 basamak.

Nasıl yapılır?

✅ Çözüm: Format Spec

{değişken:format} syntax'ı

import math
pi = math.pi  # 3.141592653589793

print(f"Pi = {pi:.2f}")      # → 3.14
print(f"Pi = {pi:.4f}")      # → 3.1416

# Binlik ayraç
print(f"{1250000:,}")        # → 1,250,000
print(f"{1250000.5:,.2f}")    # → 1,250,000.50

# Yüzde
print(f"{0.854:.1%}")       # → 85.4%

Format Spec Hatırlatma

YazımAnlamı
{x:.2f}2 ondalık basamak
{x:,}Binlik ayraç (1,250,000)
{x:,.2f}Hem binlik hem ondalık
{x:.1%}Yüzde (otomatik ×100)
{x:>10}Sağa yasla, 10 karakter
{x:<10}Sola yasla, 10 karakter
{x:0>6}6 karakter, 0 ile doldur

SQL Bölümü

  • Subquery — sorgu içinde sorgu
  • WITH — isim verilmiş subquery
  • VIEW — kalıcı subquery

Python Bölümü

  • % → .format() → f-string
  • Format spec: .2f, ,, %
  • Hizalama: >, <, 0>

Ev Ödevi 📝
